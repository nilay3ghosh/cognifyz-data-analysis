# Cognifyz – Data Analysis & Machine Learning Tasks

## 📌 Overview
This repository contains solutions for multiple data analysis and machine learning tasks as part of the Cognifyz program.

---

## 📁 Folder Structure

### 🔹 Task 1: Exploratory & Geospatial Analysis
- Data Exploration and Preprocessing
- Descriptive Analysis
- Geospatial Analysis (Map visualization using latitude & longitude)

### 🔹 Task 2: Feature Engineering & Price Analysis
- Feature Engineering
- Table Booking & Online Delivery Analysis
- Price Range Analysis
- Engineered Dataset & Model Performance Results

### 🔹 Task 3: Visualization & Predictive Modeling
- Customer Preference Analysis
- Data Visualization
- Predictive Modeling (Regression models)

---

## 🛠️ Technologies Used
- Python
- Pandas

- Matplotlib
- Seaborn
- Scikit-learn
- Folium
