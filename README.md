# 📊 Cognifyz – Data Analysis & Machine Learning Tasks

## 📌 Overview

This repository contains data analysis and machine learning projects completed as part of the **Cognifyz Data Analysis Program**.

The project focuses on exploring real-world datasets, performing data preprocessing, extracting meaningful insights, creating visualizations, conducting geospatial analysis, and developing predictive regression models.

It is organized into three major tasks, covering different stages of the data analytics and machine learning workflow.

## 🎯 Project Objectives

- Perform exploratory data analysis (EDA).
- Clean and preprocess raw datasets.
- Analyze geographical patterns using latitude and longitude.
- Apply feature engineering techniques.
- Explore pricing, table booking, and online delivery trends.
- Understand customer preferences through data visualization.
- Develop regression models for predictive analysis.

2. Interview questions and answers
A. Project overview
Q1. Tell me about your Cognifyz project.

I completed a series of data analysis and machine learning tasks as part of the Cognifyz program. The work was divided into three stages: exploratory and geospatial analysis, feature engineering and price analysis, and visualization with predictive modeling. I used Python libraries such as Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, and Folium to explore data, generate insights, and build regression models.

Q2. What was the main objective?

To extract useful insights from raw data, identify customer and business patterns, and explore predictive modeling techniques.

Q3. What is EDA?

Exploratory Data Analysis is the process of examining a dataset to understand its structure, distributions, missing values, outliers, and relationships between variables.

Q4. Why did you divide the project into three tasks?

Each task addresses a different stage of the analytical workflow: understanding data, engineering features, and analyzing patterns or building predictive models.
B. Task 1 – Exploratory and geospatial analysis
Q5. What is data preprocessing?

Data preprocessing is the process of preparing raw data for analysis or machine learning by handling missing values, duplicates, inconsistent formats, and other data-quality problems.

Q6. What is descriptive analysis?

It summarizes data using measures such as mean, median, mode, minimum, maximum, standard deviation, and frequency distributions.

Q7. What is geospatial analysis?

Geospatial analysis examines data based on geographical locations, coordinates, or spatial relationships.

Q8. What are latitude and longitude?
- Latitude represents a location's position north or south of the Equator.
- Longitude represents its position east or west of the Prime Meridian.
Q9. Why did you use Folium?

Folium is a Python library for creating interactive geographical maps using Leaflet.js. It can display locations and spatial patterns using markers and other map layers.

Q10. What is an outlier?

An outlier is a data point that differs significantly from the general pattern of the dataset.
C. Task 2 – Feature engineering and price analysis
Q11. What is feature engineering?

Feature engineering is the process of creating, transforming, or selecting variables to make data more useful for analysis and predictive modeling.

Q12. What is the difference between feature selection and feature engineering?
- Feature selection chooses relevant existing variables.
- Feature engineering creates or transforms variables to improve their usefulness.
Q13. What is price range analysis?

It examines how prices are distributed across categories or groups and helps identify pricing patterns.

Q14. What is table booking analysis?

It examines the availability or distribution of table-booking services and how they relate to other business variables.

Q15. What is online delivery analysis?

It examines online delivery availability and its relationship with variables such as price, customer preferences, or other business attributes.

Q16. What is encoding?

Encoding converts categorical variables into numerical representations that machine learning algorithms can process.
D. Task 3 – Visualization and predictive modeling
Q17. What is data visualization?

Data visualization represents data graphically to make patterns, comparisons, and trends easier to understand.

Q18. What is the difference between Matplotlib and Seaborn?

Matplotlib is a general-purpose plotting library. Seaborn provides a higher-level interface for statistical visualization and works closely with Pandas.

Q19. What is regression?

Regression is a supervised machine learning technique used to predict continuous numerical values.

Q21. What are independent and dependent variables?
- Independent variables are the input features used to make predictions.
- The dependent variable is the target value being predicted.
Q22. What is Scikit-learn?

Scikit-learn is a Python machine learning library that provides tools for preprocessing, model training, prediction, and evaluation.

Q23. What is overfitting?

Overfitting occurs when a model learns training data too closely, including noise, and performs poorly on unseen data.

Q24. What is underfitting?

Underfitting occurs when a model is too simple to capture the underlying patterns in the data.
E. Model evaluation and Python
Q25. What is train-test splitting?

It divides a dataset into training and testing subsets. The training subset is used to train the model, while the testing subset evaluates its performance on unseen data.

Q26. What is R-squared?

R-squared measures the proportion of variance in the target variable explained by the regression model.

Q27. What is MAE?

Mean Absolute Error measures the average absolute difference between actual and predicted values.

Q28. What is MSE?

Mean Squared Error calculates the average squared difference between actual and predicted values.

Q29. What is RMSE?

Root Mean Squared Error is the square root of MSE and measures prediction error in the same units as the target variable.

Q30. Why did you use Pandas?

For reading datasets, cleaning data, filtering rows, handling missing values, grouping records, and performing data transformations.

Q31. Why did you use NumPy?

For efficient numerical operations, arrays, mathematical calculations, and data manipulation.

Q32. What is correlation?

Correlation measures the strength and direction of association between two variables. It does not, by itself, prove causation.

Q33. What is the difference between classification and regression?
Classification	Regression
Predicts categories	Predicts continuous values
Example: Spam or not spam	Example: House price
Accuracy, precision, recall	MAE, MSE, RMSE, R²

Q34. What is a correlation matrix?

It is a table showing pairwise correlation coefficients between numerical variables.
F. Practical and advanced questions
Q35. How would you handle missing values?

I would first identify the amount and pattern of missing data. Depending on the variable and business context, I could remove affected records or use mean, median, mode, or other suitable imputation techniques.

Q36. How would you handle categorical data?

Using techniques such as one-hot encoding or ordinal encoding, depending on whether the categories have a meaningful order.

Q37. What is normalization?

Normalization scales numerical features to a common range, often between 0 and 1.

Q38. What is standardization?

Standardization transforms features to have approximately zero mean and unit standard deviation.

Q39. Why is data leakage dangerous?

Data leakage occurs when information unavailable at prediction time enters model training. It can produce misleadingly high evaluation scores.

Q40. How would you improve this project?

I would add cross-validation, hyperparameter tuning, more model comparisons, robust feature selection, and an interactive dashboard to communicate the analytical findings.
